# About Awesome Rust Tools and Frameworks

Awesome Rust Tools and Frameworks is a curated, continuously updated directory of the Rust ecosystem's building blocks — the frameworks, libraries, crates and developer tools people reach for when they build with Rust.

## What you'll find here

- **Frameworks** — web, async/networking, GUI and game frameworks.
- **Developer tooling** — cargo plugins, linters, formatters, testing, benchmarking and observability tools.
- **Libraries and crates** — databases and ORMs, serialization, WebAssembly, embedded and systems programming.

## How the directory is maintained

The directory is built and maintained with the [Ever Works](https://ever.works) platform. AI agents research new projects, keep existing listings current and organize everything into categories and tags; every listing links back to its repository, crates.io page or project website.

Maintaining a Rust project that isn't listed? Use the **Submit** page to add it.
