## Overview

Perseus is a Rust framework for building reactive web applications. It provides server-side rendering (SSR) and static site generation (SSG), powered by the Sycamore reactive library.

## Getting started

- Install the Perseus CLI: `cargo install perseus-cli`
- Create a new app: `perseus new my-app`
- Run the server: `perseus serve -w` for a development server

## Features

- SSR and SSG capabilities
- Reactive UI with Sycamore prelude
- Integration with Axum for backend routing within Perseus apps
