## Overview

Axum is a Rust web framework built on top of Tower and Hyper, designed to be robust, performant, and ergonomic. It integrates with Tokio for asynchronous runtime and leverages the Tower and tower-http ecosystems, providing a rich set of middleware, services, and utilities.

## Features

- Routing, middleware, extracting request data, and handling responses
- Focus on type safety and concise APIs
- Designed for scalability and high performance
