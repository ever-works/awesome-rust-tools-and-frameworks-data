## Overview

Bevy is a data-driven game engine for Rust built around an Entity Component System (ECS). It enables modular game development with a focus on data-driven design.

## Features

- ECS-based architecture for modularity
- 2D and 3D rendering
- Bevy UI for dynamic interfaces (in code or scene format)
- Graph-based rendering flow
- Hot asset reloading via the default plugin

## Notes

Bevy is still under active development and may introduce breaking changes in minor releases.
