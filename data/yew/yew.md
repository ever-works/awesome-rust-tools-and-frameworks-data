## Overview

Yew is a popular Rust framework for building modern web applications with a component-based architecture inspired by React. It supports state management and async features, and commonly pairs with the Trunk bundler for development.

## Getting started

- Install Trunk and a Yew template, then generate a project with `cargo generate --git https://github.com/yewstack/yew-trunk-minimal-template`, and start with `trunk serve --open`.

## Features

- Component-based UI model
- Async capabilities and ecosystem tooling
- Trunk-based development workflow
