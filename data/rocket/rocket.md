## Overview

Rocket emphasizes simplicity and ease of use with type-safe, boilerplate-free development. It provides routing with attributes, declarative form handling, JSON (Deserialize/Serialize), templating, WebSockets, and middleware.

## Features

- Routing with attributes
- Form handling and JSON support
- Templating and WebSockets
- Middleware
- Built-in testing library
