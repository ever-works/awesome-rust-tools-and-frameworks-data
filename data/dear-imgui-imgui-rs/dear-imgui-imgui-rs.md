## Overview

Dear ImGui (the C++ library) has Rust bindings via the imgui-rs project. It is designed to be embedded in existing engines and supports multiple renderers and backends.

## Bindings/Backends

- imgui-rs core bindings
- imgui-winit-support
- winit integration
- imgui-glow-renderer (render backend)
- imgui-glium-renderer (deprecated)

## Notes

The ecosystem includes multiple renderers and there has been some churn with deprecated backends.
