## Overview

Loco targets solo developers, aiming to simplify building, iterating, and scaling Rust applications. It includes built-in services, data management, email handling, background jobs, tasks, and a CLI.

## Features

- Batteries included: built-in services, data management, email, background jobs, CLI
- Rails-inspired productivity for solo developers
- Scalable architecture and modular design
- Test-driven development tooling

## Usage

The Loco CLI can generate project scaffolding (e.g., loco new).
